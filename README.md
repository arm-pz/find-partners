# find-partners

An agent skill for Claude Code, Codex and Cursor that finds partners, not link swaps: newsletters,
publishers and complementary tools your buyers already read. It screens out pay-to-post sites and
drafts one collaboration ask each: a guest post, an expert quote, co-made data, an integration
listing or a podcast. Ask it to swap links and it explains once why that's risky, then does this
instead.

    npx skills add arm-pz/find-partners --skill find-partners

Ask it things like:
- "Find non-competing SaaS companies we could co-market with."
- "Who could we guest post for in the freelancer niche?"
- "Swap links for me."

See a real run: [skillsmith.tech, November 2026](https://github.com/arm-pz/clauderepo/tree/ccr-e894c200-72sjk2/proof/skillsmith-tech): 7 partners kept, 1 link seller
dropped, 4 asks drafted.
